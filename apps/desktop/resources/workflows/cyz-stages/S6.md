# S6 · 真实材料的处理与分析

先盘点本轮实际有的数据、文献编码或其他研究材料，并核对所需条件。无数据时只交付分析计划；模拟演示若由用户要求，必须持续标明模拟，不能写入真实研究结果。无需新数据采集的研究不强造采集环节。

保留原始文件，在工作副本处理，记录数据含义、来源、排除、缺失、异常与转换。选择与问题和设计匹配的分析：量化关注假设、独立性或嵌套、效应与不确定性；质性保留编码、主题形成、支撑片段和反例。工具未运行的分析标为计划，不根据代码或预期猜测运行结果。

结果按问题组织，数值与实际输出逐项对应；文献或质性主张能找到材料位置。不隐藏不显著、负面或相反证据，不把相关关系扩大为因果。说明样本、情境和设计对解释的限制。

交付已执行的分析、可复核步骤及结果说明，或明确的待执行计划。记录版本和未解决项，便于下一个模型接手；本轮只检查一张表或一个结果时，不宣称全部数据通过。
