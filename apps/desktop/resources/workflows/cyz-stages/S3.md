# S3 · 指定文献的筛选与阅读

用户指定一篇论文时就围绕这一篇和本轮问题阅读；多篇筛选时才做去重、纳排和排除记录。按需求选择快速了解、标准阅读或关键证据深读；题录与摘要不能支撑全文方法评价或精确结果主张。

先说明实际可读范围，再解释研究问题、设计、结果、局限和对当前问题的启发。关键引文、数值、图表和公式须定位到原页或稳定段落；区分作者陈述、用户判断与模型解释。提取不清的区域保留不确定性，不补造内容。

原文能够直接阅读时即可核验，不要求为了走流程先转换全部 PDF。有合格缓存则核对来源后复用；新建缓存仅是阅读辅助，保留原文和页码对应。Windows MinerU Desk 只在实际可用的 Windows 环境中使用；macOS/Linux 不执行 Windows 安装或注册表步骤。缺少解析能力时使用可读材料完成部分任务并说明限制，不自动上传论文或下载大模型。

若实际选择随包备用转换器，先确认当前 Python 的 PyMuPDF 或 pypdf 可用，并如实提供备用原因；不能虚构一次 MinerU 失败来满足参数。缓存生成不代表原文主张已核验。

交付本轮阅读笔记和来源位置；筛选任务另附理由。持续项目可同步文献卡和证据矩阵，一次性读论文无需创建整套研究目录。
