# S0 · 方向探索

适用于尚未明确选题的探索。已有清楚想法时只补它所缺的方向比较，建议转入问题打磨，不再广泛扫描。先从用户材料和已知教学场景确定有用的检索边界；缺少决定性边界才问一个问题。

复用种子文献，从代表性综述或论文梳理“研究什么问题、怎么取得证据、得到什么结论及限制”。先扫描，多数论文无需全文深读；只对影响方向选择的代表或矛盾材料补核验。实际检索须记录来源、检索式、日期、覆盖及停止理由；无联网工具时输出有标注的初步设想和检索建议，不假称完成领域扫描。

按价值、已有依据、可获得材料和实施难度比较候选方向。不凑固定数量，不把换一个场景或暂未找到论文当成创新。新检索不再改变候选与关键不确定性，或用户已选方向时结束本轮。交付时推荐方向并列出待决定项；未获用户确认只记录建议，不替用户确定选题。

持续项目可把方向比较保存在研究起点记录中；标准模板的候选卡供有需要时使用，不要求一次性探索填写全部内部字段。
