# S1 · 问题打磨

保留用户的原始说法，从现有成熟度继续：模糊兴趣需要比较切入点，已有题目需要明确问题，已有问题或方案则核查依据和可行性。用户已限定只处理其中一项时，集中处理该项，不要求重新做完整候选卡。

区分方向、题目、研究问题和适用时才有的假设。明确对象或材料、情境、核心概念、主问题及研究类型；理论与综述问题不强制改造成实验假设。把问题与可获得证据对应，区分已有材料、可获取材料和需要新增采集的材料。

对会改变问题的关键疑点做定向核查：最接近的研究是否已回答，是否有更简单的解释或反证，何种结果会否定当前设想，实施与必要伦理条件是否可行。缺少证据时保留待核验结论；不能凭标题变得漂亮就确认问题成熟。

交付问题卡或约定的局部修订，说明与原想法的关系、范围、证据路线、备选解释和结论边界。仅在需要定方向或更改已有核心决定时请用户确认。持续项目保留前后版本与理由；未确认的推荐不得写成用户决定，也不得把本轮改完问题当成后续研究已经通过。
