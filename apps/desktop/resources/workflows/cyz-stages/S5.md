# S5 · 与问题相符的研究设计

从已明确的研究问题和证据需要出发，审查本轮方案或其中指定部分。对每个相关问题说明需要什么证据、怎样取得和分析、结果怎样支持或限制回答；不先指定一种方法再强改问题。

量化、质性、混合、行动研究、设计研究、文献综述和理论研究分别按实际需要组织。综述或理论研究不强制安排实验、新样本或统计检验；量化方案要考虑测量、混杂、班级嵌套、缺失与不确定性；质性方案要说明取样、资料、编码或主题形成、反例及可追溯性；混合方法须交代两类证据怎样结合。

核对时间、材料、场景和工具是否可落实，区分已有条件与未来计划。涉及人员尤其学生数据时，列出采集前必须解决的同意、隐私及适用伦理条件，不冒称已获批准。仅审查一项方法的任务不扩成完整实施方案。

交付约定范围的方案或修订建议，标明选择理由、备选方法、待解决条件及不能支持的结论。重大方法和资源取舍须由用户决定；模型建议、已确认决定和实际完成事项分别记录。
