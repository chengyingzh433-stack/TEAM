# TEAM artwork

TEAM uses an original geometric T and four collaboration nodes: three ivory nodes and an amber junction on deep green. The SVG source and generated PNG/ICNS are under the project MIT license. `provenance.json` records the current raster hash. The previous Lancer artwork remains in local history; it is not the TEAM release icon.

Bundled third-party workflow resources retain their original licenses. Provider marks and user-uploaded portraits are not covered by this artwork license.
