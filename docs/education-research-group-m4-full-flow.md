# AC33 新融合量化全链路：用户演练准备

状态：准备完成，真实运行未执行，AC33 未验收。版本：2026-11-14，`fusion-v2`。此清单不启动模型，不使用旧七阶段最终稿作为新稿。当前能力见 [使用说明](education-research-group.md)，跨进程故障组合见 [恢复清单](education-research-group-m4-recovery.md)。

## 开始前固定

在独立工作目录与新课题中登记以下内容，原课题、原稿、课程库和会话只读保留：

- 运行编号、日期、操作者、源码提交、实际应用版本／路径、工作目录、新课题 ID、四个角色会话 ID。
- 一个尚待研究确认的想法，入口选择“已有想法”，目标“完整论文”，路径“有限量化”，流程 `fusion-v2`。不要导入旧终稿或沿用旧接受许可。
- 真实可取得教育研究原文与公开／授权数据：原始地址、取得日期、分发许可、文件 SHA256、变量字典、缺失编码和样本限制。先确认设计适配现有描述统计／OLS 能力；工具不支持的方法保留缺项，不改数据迎合方法。
- 实际模型／提供商／思考强度、阶段角色配置、工具版本、方法库固定版本、项目与应用容量。至少预登记一次跨阶段模型变更，必须有两个真实可用配置；不可用则记录阻断，不用同模型改名代替。
- 本轮规模、Token 准入额度、可接受费用、人工停止条件、操作者确认及时间。记录未知计价和在途消耗可能超限的边界。旧配置的额度不自动构成本次授权。
- 资料批次拆分规则、一次中途材料变更、可执行的复核与质量标准。不要为了满足“实质反馈”伪造争议或数字；若没有出现真实修订，AC33 相应证据仍缺失。

如原文不可访问、数据未授权、模型配置不可用，记录原因和取得方式，暂停相关任务。不要清空失败课题重来后称首次通过。

## 阶段、操作与退出证据

| 阶段          | 用户执行与核对                                                                    | 需要保存的实际证据                                                               |
| ------------- | --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| S0／入口      | 从想法进入，确认问题边界、本轮目标和研究路径；没有探索需求不强制补造 S0 产物      | 创建配置、原始任务、明确决定与未决项                                             |
| S1 问题       | A/B 独立判断后互读，导师确认研究问题及尚需核实的假设                              | 独立初稿／风险、实际读取记录、当前稿及裁定                                       |
| S2 检索       | 实际检索／导入来源记录，保存检索式、数据库、时间、去重与筛选理由                  | 检索结果与失败、来源身份和读到的范围；不能只有预拟检索式                         |

| S5 设计       | 核对变量、样本、缺失处理、方法适配、伦理与边界；方案接受与实施条件分别登记        | 方案、结构化分析计划、B 审阅、材料可用性及用户实际许可                           |
| S6 分析       | 实算登记计划，B 按同一参数复跑并审阅解释；中途新数据先检查变更范围再采用          | 数据 SHA、计划 ID、实际结果／复算目录、数字字段绑定、局限；无 p 值不补造显著性   |
| S7 写作       | 正文引用实际来源和结果，保存 A/B 实质修订链；语言修改保留前后稿及语义检查         | 固定稿件 ID／SHA、来源／分析 ID、数值／主张／方法／语言意见                      |
| S8 终审       | 导师和复核者针对同一稿，未决要求不能被旧意见越过                                  | 当前内容意见、导师裁定、用户决定；区分程序通过与内容接受                         |
| 文稿与归档    | 导出当前版本 Word／Markdown／HTML／溯源，再显式选择可分发材料生成归档             | 文件指纹与同版对照、缺项及取得方式、在新目录导入的新暂停课题；实际打开由用户检查 |

导航按依赖局部推进，不必等待全组同步。阶段到达不等于内容已接受；分析等待期间可以保留已接受方案，补数据后只复查相关范围。路径与真实研究不适配时记录修改，不把修改后的运行称为原计划未经干预完成。

## AC33 必留的跨阶段证据

1. **中途接力**：至少一条资料成果发布时间、消费者实读时间、生产者真实结束时间，满足实读发生在批次结束之前。仅“同时显示运行中”不够。
2. **实际重叠**：两个以上真实成员请求的开始、首输出、结束及会话／run 身份，给出时间重叠区间。排队或模拟事件不能替代。
3. **实质反馈及版本修订**：B 的具体问题 → A 对应修改 → B 对新稿实读复核 → 导师同稿裁定，保存所有旧稿。
4. **跨阶段配模生效**：变更前后阶段、配置、实际原生请求模型与成果归属。设置截图不能单独证明生效。
5. **数字可查**：至少将关键结论中的每个数字回指到固定数据、分析计划、结果字段和复算证据；局限与设计一致。
6. **中途变更**：预登记的新来源或数据在实际运行中采用，保存版本、影响范围、旧结果处置、后续稿及导出。完整 AC34 故障组合仍另按恢复清单执行。

## 每次运行记录模板

复制下列条目到独立证据目录；不把运行证据、原文、数据或认证提交到代码仓库。

```text
runId / 日期 / 操作者：待填
源码提交 / 实际应用路径与版本 / 工作目录：待填
projectId / 导师、A、B、资料员 sessionId：待填
注册任务 / 数据与原文 manifest / SHA / 许可：待填
实际模型与阶段变更 / 容量 / 规模与预算确认：待填
开始 / 结束 / 总耗时 / 关键路径（含依据）：未运行
S0–S8 各阶段：未运行；稿件、来源、结果、读取、裁定证据路径待填
中途接力 / 请求重叠 / 实质修订 / 配模生效：未证明
中途变更及局部恢复：未运行
输入 / 输出 / 缓存读写 / 未知用量 / 金额与依据：未知
失败、取消、人工干预、返工及相关会话：未运行
最终文稿 / 归档 / 版本与指纹 / 实际打开：未生成
独立内容评阅身份（不参与作者角色）、标准、结果及局限：待评
旧 CYZ、旧课题、原稿与历史保护核对：待用户检查
结论：准备完成，功能／真实内容／常用安装仍未验收
```

每次修复后追加重试编号和关联，不覆盖原证据。若只跑到部分阶段，注明最后有效产物、缺项和下一步；旧演练可以作为参考，不能替代本次证据。

## 开发者逻辑检查范围

本批不把多个单元用例拼称完整模型演练。既有 baseline 覆盖任务依赖、资料采用版本、来源和实际分析存储、数值／主张／方法接受、语言变化、同版本文稿与归档、未知请求及损坏恢复；本批新增离线评估记录的持久化和统计检查。它们仅证明各自代码边界，不能证明真实检索质量、模型反馈、并发收益或跨进程操作。功能、真实模型及最终常用安装核对由用户执行。
