# TEAM 安装、Pi 适配与数据保护

TEAM 1.1.0-beta.1 是源码测试版。仓库带有 Pi SDK 依赖与锁文件；`pnpm install --frozen-lockfile` 安装应用运行所需的 Pi 引擎，不需要另装全局 Pi CLI。没有打包账号或模型权重，也不提供免费模型服务。

## 没有安装 Pi

按根 README 安装 Node 24、pnpm 10.34.9，安装依赖并 `pnpm dev`。在“模型与账号”配置真实可用的服务。默认 Pi 配置位于 `~/.pi/agent`；认证信息仅保存在本机，不要上传至 GitHub。

## 已经使用 Pi

1. 先退出正在操作相同会话的 Pi／旧 Lancer，备份 `~/.pi` 和原研究工作区。
2. 默认直接适配 `~/.pi/agent` 的账号、模型配置和会话位置，不复制或更改全局 `pi` 可执行文件。
3. TEAM 使用锁文件固定的 SDK，不承诺任意较新／较旧全局 Pi 的扩展和会话格式都兼容。先在独立工作目录检查账号、模型及历史可读性；失败时保留原记录，不覆盖旧数据。
4. 自定义目录可从终端启动时传入 Pi 原生环境变量，例如：

```sh
PI_CODING_AGENT_DIR="/absolute/path/to/copied-agent" pnpm dev
```

该路径是 **agent 目录**，不是其上层 `.pi`。建议先使用现有目录的备份副本。未指定时沿用 Pi 默认值。旧的本地 Lancer 启动脚本可能清除环境变量；自定义目录使用上述源码启动方式，不假定 Finder 会传递终端环境。

## 旧 Lancer 改名后的数据

TEAM 显式保留 `<appData>/Lancer` 作为默认 UI／课题状态位置，macOS 对应 `~/Library/Application Support/Lancer`。`PI_APP_USER_DATA_DIR` 仍可指定隔离目录。Pi 账号／会话目录独立解析，不能把 UI 状态目录当作 Pi agent 目录。

没有自动删除、迁移或改写研究文件。已有用户自定义助手名称／历史标题可能仍显示 Lancer，这是原记录而不是新产品名。内部包名、工具协议、bundle ID 和命令名为升级兼容保留，不按显示名批量改写。

## 研究入口

TEAM 是通用科研辅助工具，当前研究流程重点适配教育研究。创建融合课题时选择入口、本轮目标、路径和可用模型，连接自己的方法知识库。数据使用许可、伦理条件、文献访问范围和研究结论由实际材料决定，模型不能替你确认。独立 CYZ 模式继续保留。

## 构建与分发

本次发布源码 ZIP/tar.gz 及校验值，不提供预编译桌面安装器。macOS 正式打包脚本要求持续使用的签名证书；本次环境未配置，因此没有绕过该条件制作安装器。开发构建通过不代表已完成签名、公证、安装或真实模型验收。

```sh
pnpm --filter @lancer/desktop build
```

若你具备本机签名配置，可按 `docs/macos-local-signing.md` 构建 macOS 包。源码支持的平台、原生依赖和发布检查以仓库说明为准，不把打包配置等同于跨平台功能通过。
