# 教育研究课题组

本模式独立于 `cyz-paper` 工作台，包含保留的两阶段、七阶段课题，以及显式选择的 `fusion-v2` 融合版。七阶段完整范围接通研究问题打磨、初步方案审阅、文献综合、研究设计、数据分析、论文写作和全文审阅，也可只运行前期方案。其验收契约见 [完整论文流程](research-paper-pipeline.md)。融合版采用入口、本轮目标和任务依赖导航；开发与实际验收登记见 [融合版进展](team-release.md)。旧课题保持原配置、会话及历史。

## 当前使用说明（M4，2026-11-14）

本页是当前能力的统一入口。应用课题面板的“当前能力与使用说明”为简要提示；详细操作、两模式边界及验证状态以本页及链接的实施记录为准。M3 与 M4 Word、归档、恢复／投入控制的代码检查已交付，实际功能仍由用户测试。真实新融合全链路及 18 次协作对照仅已准备，尚未运行，不承诺协作提速或稿件内容正确。

### 选择模式与本轮任务

- **CYZ 论文工作台**：独立 S0–S8 阶段指导，保留既有项目和配置，见 [CYZ 说明](cyz-paper-workbench.md)。它不是四成员课题组，不把阶段切换称为多成员执行。
- **教育研究课题组**：导师、推进研究者 A、独立复核 B、资料员使用独立持续会话。新课题明确选择融合版 `fusion-v2`，选择“已有想法”等入口、本轮目标与研究路径；旧两阶段／七阶段项目保留，不能用旧七阶段演练证明新融合流程。
- 融合版支持有限量化、范围明确的文献综述、已有文本质性（反思性主题分析）、理论与概念路径。单项任务包括精读、指定引用核查、设计评估、章节修改、全文审阅；明确材料和正文范围，不自动扩大任务。
- 无数据可以完成研究方案审阅；实施和分析仍等待材料。综述、质性、理论路径有各自记录和审阅条件，不强制套统计前置。

### 从材料到同版本交付

1. 打开“配置阶段、模型与知识库”，核对本轮目标、方法库路径和实际可用模型；新课题模板与现有课题的后续配置分开。不要把课程库当已核验原文，也不要修改原课程文件。
2. 写明任务、允许使用的材料与限制，导入来源或数据。检查材料变更范围，明确采用后才进入当前版本；原稿和旧版本继续保留。联网／全文取得失败按实际记录，不补造题录、数据或伦理许可。
3. 在任务导航查看依赖、缺项和角色交接。A/B 先独立判断，再读具体成果；资料批次未结束时允许中途接力。程序执行完成、内容意见、导师裁定、用户授权是不同记录。
4. 有限量化先登记分析计划、变量、样本、缺失处理、参数和复核范围，再执行已支持的描述统计／OLS。关键数字绑定真实结果字段；同引擎复跑不等于独立算法验证。未提供的 p 值、置信区间或因果证据不能补造。其他方法需明确工具与验证边界。
5. 写作、数字／主张／方法核验及语言修改均固定目标稿。章节修改保留未选正文；来源或结果变化会使相关意见需重查。专项方法员、编辑、独立外审保留独立会话与限定上下文，历史意见不能代替新稿许可。
6. “导出当前审阅稿”只交付待核验稿，不自动接受。接受路径导出本轮接受稿；Word、Markdown、HTML 与溯源固定同一稿件。Word 支持可编辑标题、正文、表格和静态跳转目录；编辑后不自动刷新页码，复杂行内 Markdown、图片、公式及期刊排版尚有限制。旧接受包不自动补写 Word。见 [文稿交付](education-research-group-m4-plan.md)。
7. 归档前逐项选择可分发来源和数据；归档包含相对路径、指纹、缺项及取得方式。未许可原文不随包分发。导入完整校验后创建新的暂停课题，保留原项目；不恢复旧原生会话／在途请求、不执行随包脚本、不继承历史接受许可。继续研究需明确采用材料并发起新任务。见 [归档与导入](education-research-group-m4-ac16.md)。

### 模型、投入与恢复

模型按任务覆盖 → 阶段角色 → 项目默认 → 应用默认继承，原会话选择为最后回退；在途请求保留实际模型。配模应核对下一次实际运行记录，不能仅凭设置页面判断已生效。

“执行容量与任务配模”控制应用／项目共享容量和额度。降低限额只影响新增派发；“投入与未结算用量”显示成员／任务／项目／全部课题已知计数和预留，未知不算零，金额无可靠依据则未知。预留不是实际账单硬封顶。手动压缩研究会话目前拒绝，不能借此绕过准入。

暂停、失败或重启保留原角色、会话、成果及失败记录。未知执行先核实，不能直接重放；明确从未派发才可记零。取消失败保留错误和预留。主记录缺失或损坏、只能读取旧备份时进入只读保护，须核实真实请求并恢复有效主记录再重启。不要覆盖原文件来“修好”演练。见 [恢复矩阵与测试步骤](education-research-group-m4-recovery.md)。

### 与团队研讨（2026-11-16 新增，功能待用户测试）

## 融合版 M2 的操作范围

研究面板分别展示材料、登记分析、来源及原页、综合与反证、内容检查、方法包和语言修改。每条记录保留实际输入版本、稿件或结果身份；展开历史记录可以查看先前依据。任务执行完毕与稿件获接受分别显示。

- 分析先登记目的、变量、样本、缺失处理、参数及审阅计划，再执行已支持的描述统计或 OLS。B 可以读取实际结果、按同一计划复跑并给出解释意见。同引擎复跑一致与独立算法验证分开记录；未执行或未支持的计划保留其状态。
- 数值绑定固定实际结果字段、单位、舍入和稿件字符范围。数字、单位、来源或稿件变化触发相应重查；自由文字中的未绑定数值进入内容复核。主张核验同时要求实际原文读取和具名支持意见，摘要保持其实际阅读范围。
- 文献检索、记录导入、策略调整、去重和访问失败保留原记录。PDF 原页按实际需要转换并缓存，模型取得图片字节后提交原页观察；正文解析和图像阅读分别留痕。
- 综合矩阵、候选缺口和新增反证关联实际来源、读取范围及目标稿。反证可以重开相关任务，保留 A 的前后回应、B 对新稿的复核和导师对实质变化的处理；原候选及旧稿留作历史。
- 方法包固定课程版本、必要上下文和可读图像，可在同版任务间复用适用内容。项目的应用、意见和用户决定各自保存。原课程库离线或已变版时，已有融合课题只在固定缓存及图像通过实物校验后有限恢复；取得新方法仍需原库或明确的新任务。
- 语言修改由用户选择范围并固定术语、限制和披露。保存前后稿，要求 A/B 实际读取双稿并逐段说明语义是否保持；程序提示辅助定位风险。实质改变回到内容审阅，旧语言意见不能放行新的范围或新稿。

Markdown、HTML 和溯源导出固定到同一接受稿快照。导出中的新输入沿项目写入队列处理；新版本和历史交付各自标识。Word 与可搬移归档已交代码检查，功能与完整新融合路径待用户验收，具体已通过范围以进展登记中的 L／E／R／C 证据为准。

## 交付与验收契约

1. 导师、推进研究者 A、独立复核研究者 B、资料员各使用持久化的独立 Pi 会话。启动后并发派发，沿用当前模型或逐角色配置，不复制同一个会话的阶段标签冒充成员。
2. A、B 先独立形成初稿和风险判断，之后才能读取对方观点。知识库中的共同方法事实不受此限制。
3. 中间成果通过不可变、带版本的发布记录立即通知相关成员，使用 Pi 原生 steering / follow-up 通道；不经过通用子任务的同组完成屏障。
4. 跨成员读取留痕。出现实质问题时，A 修订须读取并引用 B 的批评，B 复核须读取并引用最新修订，导师读取同稿及复核后裁定。合格首稿可以在必要核验后直接接受。工具返回成功、执行完成、审阅通过是不同状态。
5. 导师可以要求补充或保留开放问题；同轮最多两次修订，超过后进入需决定状态，不自动放行。
6. 本地课程知识库单独配置、只读接入，不将课程正文复制进开源仓库。每轮锁定知识块索引摘要；检索交付完整块和递归必需上下文，保留来源和“未独立核验原论文”标记。
7. 课题组状态、交接和知识包单独持久化；重启后未结束运行进入暂停，不自动重放付费请求。暂停取消该组成员，保留产物；恢复明确补发尚未完成的工作。
8. 界面显示成员、实际运行状态、已交接/已读取记录、版本与可展开成果。旧工作台配置和历史不迁移、不覆盖。

## 结构

`electron/research-group/` 拥有独立调度、知识读取、保存和 Pi 工具接口；宿主只提供创建/发送/取消会话和变更通知。没有另写模型循环。`contracts/research-group.ts` 是前后端共享的窄契约。研究资料属于本地课题产物，不是应用设置或共享课程库的一部分。

## 历史七阶段配模验收

七个阶段均可配置名称、目标、交付物，以及四个角色的模型和思考强度。旧的按成员配模和两阶段配置继续可读，新增阶段沿用最近的成员配置，用户可逐项修改或应用推荐。旧成果不补写模型归属。新课题使用模板，暂停或已完成的课题可明确应用到后续运行。

阶段按成员自己的依赖推进，不引入全组屏障。模型通过 Pi 原生模型切换能力在请求/工具往返边界切换，同一角色保留原会话。新的成果保存实际阶段、实际模型与思考强度；配置不可用时停止并保留进度，不静默降级。建议预设只选本机可用模型，七个阶段均通过同一原生运行链实际应用配置。

验证：单元检查旧配置恢复、阶段解码、推荐缺失提示、按角色推进与实际模型记录；真实 Electron 检查侧栏和会话两处入口、阶段编辑、保存/重启及原 CYZ 工作台；原生 SDK 的确定性模型执行验证同一会话跨阶段切换后由新模型生成成果，并继续允许其他成员运行。真实提供商的混合模型演练另行记录，不能用测试提供商替代。

## 使用与建议（2026-11-07）

进入“教育研究课题组”，点击会话顶部“配置阶段、模型与知识库”；也可点击侧栏该模块的齿轮，再点“配置阶段、角色与模型”。前者可对暂停或已完成的当前课题应用配置，后者编辑新课题模板。保存不会启动请求或重写旧成果；运行中可修改模板，当前课题要先暂停。

七个阶段均可编辑名称、目标、交付物和每个成员的模型、思考强度。“沿用成员当前模型”表示保留该成员实际会话选择。“应用推荐配模”只应用本机已启用的模型；缺少任何推荐模型时说明缺项，不替换成别的模型。“快速试跑：全部 Flash”适合检查流程，其成果仍需进一步审阅。

这是按任务职责作出的初始分配，不是模型研究质量排名。导师负责路线判断和关口，A 持续推进，B 在设计、分析和终审使用更强的审查配置，资料员负责检索与整理。2026-11-07 全流程演练中 Flash 服务返回 500，因此通过配置界面明确把资料员改为 Sol / low，再从原进度继续；没有静默换模，也没有改写已完成成果的实际模型。

复杂判断默认 high；遇到难以解决的理论冲突、方法争议或全文不一致时，再考虑 max 并检查结果。low 用于快速检索和机械整理。模型与思考强度分别配置；强度名称不代表不同厂商间相同的计算量。当前不自动根据输出质量加大强度或换模型。

文献综合、研究设计、数据分析、论文写作与全文审阅均已接入。数据分析当前支持声明许可的 CSV 描述统计、Pearson 相关和普通最小二乘回归，A/B 对已冻结的主分析分别运行并复算，论文引用实际计算记录。复杂统计、质性分析或缺少必要材料时进入待决定状态。最终通过后导出 Markdown、HTML、溯源清单及复现材料。阶段顺序按研究依赖固定，暂不支持任意增加、删除或重排节点。

## 完整流程的操作范围

新课题默认完整七阶段，也可选择只做前期方案。当前提供一个结构化主分析和计划变量的描述统计；设计正文应与登记的方法、变量和参数完全一致。支持的数值方法为描述、Pearson 相关和 OLS，不输出显著性检验或置信区间。缺少实际数据、许可声明或必要原文时，不生成虚构的完整实证论文。

完整研究默认每位成员 800 万累计 Token，包含缓存读取计数，与提供商账单金额不同。到达上限保留进度并暂停，可修改当前课题上限后显式恢复。普通阶段暂停可以直接恢复；导师 hold 后，后续研究阶段提供“补充条件并重新审议本阶段”，保留旧裁定和当前成果，重新进入修订—复核—导师审阅。改变问题或分析方法需要新输入版本。

研究材料区显示来源、数据类型与许可声明、实际读取者；分析区显示参数、样本数、结果摘要以及可打开的原始结果。终稿通过后有论文、带目录网页和溯源入口。网络原文获取限定公开 HTTPS，拒绝本机和保留地址；使用 Fake-IP DNS 的代理环境可能无法直接获取，此时提供合法取得的本地原文文本。课程库仍保持只读。

## 按项目与成员对话查看

侧栏的“教育研究课题组 · 研究项目”按独立课题分组。每个项目显示名称、当前阶段和运行状态，展开后可以分别打开“导师 · 课题主线”“研究者 A · 推进”“研究者 B · 复核”“资料员”。切换对话只改变正在查看的内容，不重新启动研究。箭头可折叠项目，折叠选择会保存。

点击项目名返回该课题主线；点击标题旁的“＋”新建另一个课题。课题名称取自导师主线会话名，通过该会话的重命名菜单可以调整。未启动的草稿单列，各项目保留自己的成员、阶段设置、资料、计算与审阅记录。文件的存储位置仍由 Lancer 工作区管理。

## 七阶段真实课题验收（2026-11-07）

在真实 Electron 和本机实际提供商中，以 UCI 的 395 条数学课程记录及两篇实际取得相关原文的研究文献，完成问题打磨至全文终审。固定四个原会话，产出 52 份不可变成果、6 份课程方法知识包、37 次原文读取；53 次跨成员读取发生在生产者仍运行时，覆盖七个阶段。A/B 分别执行描述与已登记 OLS，四份结果和对应数据、参数、复算脚本均保存。

本次并非一次无干预首跑：Flash 服务 500 后通过界面明确改配资料员为 Sol/low；分析阶段因文字计划与结构化计划不一致、错误使用阶段 hold，保留原记录并在补充条件后重新审议，收窄到已登记模型，经过新修订、B 复核及导师裁定后继续。后续修复使分析完整稿须先完成主计算，设计正文不得承诺未登记次分析，导师中途澄清通过定向消息进行。没有强制通过旧稿，也没有删除失败记录。

独立数值核验采用 Python 标准库的正规方程与主元消去，核对 Lancer 的重正交化 QR 结果；回归系数、R² 和残差 RMSE 的最大绝对差为 6.705747068735946e-14。此项不等于独立重现所引研究。导出 HTML 使用实际 file: 地址在本机 Chrome 检查，桌面与窄屏目录有效，两张实算表均无页面横向溢出。

另以确定性提供商的真实 Pi 会话完成两个独立课题，验证项目分组、八个不同成员会话、跨项目切换、折叠持久化，以及分析阶段暂停—应用重启—恢复—终稿。旧 CYZ 工作台和旧两阶段课题均通过桌面回归。暂停过程中发现的旧 running 快照覆盖 idle 问题，已通过原生事件队列的最小复现修复，并保留回归用例。
