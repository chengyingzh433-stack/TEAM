# 通用协作版本：移除业务功能

本次范围：实际删除小红书、竞品调研、视频复刻的产品实现。保留论文查询、GitHub 研究、Lancer 自举，以及通用对话、模型配置、助手、自定义模块、工作流、并行子会话与结果回传。

## 验收目标

- 新用户和已保存旧模块配置的用户都不再看到三个被移除的内置模块。
- 旧会话与文件保留；原模块会话归入普通会话，仍可打开、重命名、移动和归档。
- 删除视频专用界面、轮询、IPC、下载/分析/复刻引擎、进程契约和打包资源；豆包 App 的普通消息连接保留。
- 通用协作树不再依赖视频流程定义；自定义模块和各模型的分支任务保持可用。
- 不修改账号、不发起真实模型请求、不删除用户媒体、会话或历史验收资料。

## 验证计划

1. `pnpm check`：格式、lint、架构边界、类型检查、仓库基线和单元测试。
2. Electron Core：模块管理、工作流、助手并行、任务树、豆包普通消息、工作区导航与终端；新增升级场景验证旧模块会话仍可访问。
3. 可见 Electron：运行隔离配置的设置/导航 smoke，保存改后截图，重启确认。
4. 搜索源代码和新构建产物，确认视频入口与执行接口已移除。

真实模型通信、真实豆包控制、Windows/Linux 和签名安装包不在本轮无账号验证的证据范围内。

- 集成终端 4 项全部通过：独立终端、输出保留、设置、普通及大文本粘贴。日志：`.artifacts/module-removal-terminal.log`。

并行和模型交接测试使用本地确定性模型，实际走 Pi 运行时、IPC、持久化和 Electron UI；它们不是外部模型服务调用或商业模型质量的证明。升级测试没有真实模型请求。

## 模块边界与保留内容

小红书和竞品调研原本主要是模块定义与阶段预设；视频复刻另有专用引擎，穿过了前端、IPC、主进程、豆包收件和构建资源。本次删除了这些实现及其专用测试，未用开关隐藏它们。协作树改用独立的模型展示数据，不再导入原业务演示场景；原演示入口已移除，几何算法用到的静态样本移入测试目录。

`electron/orchestration/`、`packages/pi-sdk-driver/`、`parallel-tasks.tsx`、`parallel-tree.ts` 继续承载通用协作。保留模块仍通过统一的自定义工作流机制配置模型、技能、目标和交付要求。

旧模块 ID 只在兼容读取与拒绝重新保存旧预设的逻辑中保留。历史会话不改名、不删除，读取时归入常态会话。第一次读取旧配置不写磁盘；之后正常保存通过既有原子写入机制保留备份。

此前安装的系统 FFmpeg/FFprobe、yt-dlp 未卸载，桌面启动器、环境示例和部署检查已取消对它们的要求。仓库的可选宣传素材制作工具 `video/` 与历史文档、旧验收资料仍保留，它们不参与桌面运行，也不是视频复刻功能。
