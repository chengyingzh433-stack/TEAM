# TEAM macOS 安装测试版

版本：1.1.0-beta.2。适用于 Apple Silicon（M 系列）Mac，最低系统目标 macOS 13。Intel Mac 暂不提供此包。

## 下载与安装

1. 在 [TEAM 发布页](https://github.com/chengyingzh433-stack/TEAM/releases/tag/v1.1.0-beta.2)下载 `TEAM-1.1.0-beta.2-arm64-preview.dmg`。
2. 打开 DMG，将 **TEAM.app 拖到 Applications（应用程序）**，复制完成后推出磁盘映像。
3. 从应用程序打开 TEAM。在“模型与账号”中配置自己的账号或 API Key，并选择实际可用的模型。
4. 添加自己的工作区、研究材料和方法知识库，再创建课题。模型服务费用由自己的账号承担。

不需要安装 Node、pnpm、Xcode、Homebrew 或全局 Pi CLI。应用随包包含 Electron／Node 运行时、锁定的 Pi SDK、生产依赖、原生 helper，以及固定版本的 rg／fd 搜索工具和许可文件。不会在首次启动时执行全局 Pi 安装、改写 shell 配置或代填账号。

同一发布页提供 ZIP 备用包及 SHA256SUMS 校验文件。ZIP 解压后同样把 TEAM.app 放入应用程序。保留的源码包面向开发者，普通使用者下载 DMG 即可。

## 当前签名状态

这是**未公证安装测试版**，仅使用 ad-hoc 技术签名保证包结构完整，不具备 Apple Developer ID 身份，也没有 Apple 公证。首次从互联网下载打开时，macOS 可能阻止启动。

只从本项目发布页获取文件并核对版本；确认来源可信后，可按 [Apple 官方说明](https://support.apple.com/en-us/102445)在“系统设置 → 隐私与安全性”查看本次阻止记录，并由你决定是否使用“仍要打开”。如果设备由单位管理或系统没有此选项，不承诺可以打开。不要关闭 Gatekeeper，也不需要运行清除隔离属性的终端命令。

要向普通用户提供经过 Apple 验证的首次启动体验，维护者仍需配置 Developer ID Application 证书并完成公证。本测试包不冒充已签名公证正式版。

## 已有 Pi 或 Lancer／TEAM 数据

安装前退出旧版，并备份研究工作区、`~/.pi` 和 `~/Library/Application Support/Lancer`。这些数据不在应用包里，替换 TEAM.app 不应删除它们。应用沿用原 Lancer 数据目录；没有为了改名进行自动迁移。

已有 Pi 默认仍使用 `~/.pi/agent`，不替换系统的 `pi` 命令；新用户在应用内自行配置。不要同时让不同客户端修改同一个正在运行的 Pi 会话。已有全局 Pi 版本、第三方扩展或自定义目录的兼容范围见 [Pi 适配说明](team-install.md)。

开发启动器与完整应用可能都显示 TEAM。安装完整包后从“应用程序”中的 TEAM 打开，测试前退出另一入口，不同时运行两个客户端。开发启动器可以保留作回退，不要删除原源码和数据目录。

## 包含范围与验证边界

- 主应用及 Pi 运行依赖随包提供；账号、模型权重、私人课程正文、课题、原稿和会话不随包分发。
- 内置有限量化计算在应用内执行，不依赖用户安装 Python。外部脚本、Git 工作流、PDF/OCR、视频工具以及 Word/WPS 等可选软件有各自依赖，安装主应用不等于这些外部工具全部可用。
- 维护者核对代码逻辑、存储、类型、lint、架构、格式、构建、应用包依赖、签名完整性和 DMG 文件；界面、真实模型、实际安装与研究功能由用户测试。未执行 18 次协作对照，不承诺研究结论正确。
- 包内运行时检查使用空账号、隔离目录、应用自带的 Node 模式和仅系统命令 PATH；不打开 GUI、不访问真实账号、不请求模型。它证明依赖可加载，不能替代实际用户功能验收。
